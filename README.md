# MedTech Data Platform

A React application for uploading, enriching, visualizing, and exporting medical/health data.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Current features

- **CSV upload** — drag-and-drop or click to browse (max 10 MB)
- File validation and error handling
- Parsed data preview with column headers and row count

## Planned features

- Data enrichment
- Interactive visualizations
- Export to multiple formats

## Tech stack

- React 18 + TypeScript
- Vite
- PapaParse (CSV parsing)
